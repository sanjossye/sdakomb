1. Konsep Dasar Algoritma Dijkstra

Algoritma Dijkstra adalah algoritma pencarian jalur terpendek (shortest path) dari satu node sumber ke semua node lain pada sebuah graf berbobot dengan bobot non-negatif. Dikembangkan oleh ilmuwan komputer Belanda Edsger W. Dijkstra pada tahun 1956, algoritma ini termasuk dalam kategori greedy algorithm karena setiap langkahnya selalu memilih node dengan jarak minimum yang belum dikunjungi.

Dalam implementasi ini, graf direpresentasikan sebagai adjacency matrix berukuran 7×7 untuk 7 node (A sampai G). Algoritma mencari jarak terpendek dari node A (indeks 0) ke node B (indeks 1) beserta jalurnya.

Prinsip Kerja Dijkstra:
  • Mulai dari node sumber dengan jarak = 0, semua node lain = ∞ (INT_MAX)
  • Setiap iterasi: pilih node belum dikunjungi dengan jarak terkecil
  • Perbarui jarak tetangga-tetangganya jika jalur lewat node ini lebih pendek (relaxation)
  • Tandai node sebagai sudah dikunjungi (set[] = true), tidak diproses ulang
  • Ulangi hingga semua node dikunjungi
Terminologi Penting:
  • Graf (Graph): kumpulan node/vertex yang dihubungkan oleh edge/sisi
  • Bobot (Weight): nilai numerik pada setiap edge, merepresentasikan jarak/biaya
  • Node Sumber (Source): titik awal pencarian jalur terpendek
  • Relaxation: proses memperbarui jarak jika ditemukan jalur yang lebih pendek
  • Visited Set: kumpulan node yang sudah diproses dan tidak akan diubah lagi
  • Parent Array: menyimpan node sebelumnya untuk merekonstruksi jalur

2. Representasi Graf (Adjacency Matrix)

Graf direpresentasikan sebagai matriks 7×7 di mana graf[i][j] menyimpan bobot edge antara node i dan node j. Nilai 0 berarti tidak ada edge langsung antara kedua node tersebut.

C++ 
int n = 7;
int graf[7][7] = {
//   A  B  C  D  E  F  G
    {0, 0, 3, 0, 0, 2, 0},  // A
    {0, 0, 0, 1, 2, 6, 2},  // B
    {3, 0, 0, 4, 1, 2, 0},  // C
    {0, 1, 4, 0, 0, 0, 0},  // D
    {0, 2, 1, 0, 0, 3, 0},  // E
    {2, 6, 2, 0, 3, 0, 5},  // F
    {0, 2, 0, 0, 0, 5, 0}   // G
};

Tabel Adjacency Matrix

B 0 0 0 1 2 6 2

Cara Membaca Matriks:
  • graf[0][2] = 3 → ada edge dari A ke C dengan bobot 3
  • graf[0][5] = 2 → ada edge dari A ke F dengan bobot 2
  • graf[1][3] = 1 → ada edge dari B ke D dengan bobot 1
  • graf[i][j] == 0 → tidak ada edge langsung antara node i dan j
  • Matriks ini simetris karena graf tidak berarah (undirected)

3. Fungsi jarakMinimum()

Fungsi jarakMinimum() bertugas menemukan node dengan jarak terkecil di antara semua node yang belum dikunjungi (set[i] == false). Fungsi ini dipanggil setiap iterasi oleh fungsi dijkstra() untuk menentukan node mana yang harus diproses berikutnya.

C++ 
int jarakMinimum(int jarak[], bool set[], int n)
{
    int kecil = INT_MAX;  // Mulai dengan nilai tak hingga
    int indeks;

    for (int i = 0; i < n; i++)
    {
        // Hanya periksa node yang belum dikunjungi
        if (set[i] == false && jarak[i] <= kecil)
        {
            kecil = jarak[i];
            indeks = i;   // Simpan indeks node dengan jarak terkecil
        }
    }

    return indeks;  // Kembalikan indeks node terpilih
}
Cara Kerja jarakMinimum():
  • Parameter jarak[]: array berisi jarak terbaik saat ini ke setiap node
  • Parameter set[]: array boolean, true = sudah dikunjungi
  • Iterasi semua node, lewati yang set[i] == true
  • Lacak node dengan jarak[i] terkecil, simpan indeksnya
  • Kembalikan indeks node tersebut agar dijkstra() memprosesnya
⚠️ Catatan Implementasi:
  • Fungsi ini berjalan dalam O(n) per panggilan — total O(n²) untuk seluruh algoritma
  • Implementasi yang lebih efisien menggunakan priority queue (min-heap) untuk mencapai O((V+E) log V)
  • INT_MAX dari <climits> digunakan sebagai representasi "tak hingga"

4. Fungsi dijkstra()

Fungsi utama dijkstra() mengimplementasikan keseluruhan algoritma. Ia menginisialisasi tiga array penting (jarak, set, parent), menjalankan iterasi sebanyak n kali, dan di akhir merekonstruksi serta mencetak jalur terpendek dari A ke B.

Inisialisasi Array

C++ 
void dijkstra(int graf[7][7], int awal, int n)
{
    int jarak[7];   // Jarak terpendek dari node awal ke tiap node
    bool set[7];    // true = sudah dikunjungi/diproses
    int parent[7];  // Node sebelumnya dalam jalur terpendek

    // Inisialisasi: semua jarak = tak-hingga, belum dikunjungi
    for (int i = 0; i < n; i++) {
        jarak[i] = INT_MAX;
        set[i] = false;
        parent[i] = -1;   // -1 = belum ada parent
    }

    jarak[awal] = 0;  // Jarak dari sumber ke dirinya sendiri = 0

Loop Utama (Relaxation)

C++ 
    for (int i = 0; i < n; i++)
    {
        // 1. Pilih node belum dikunjungi dengan jarak terkecil
        int m = jarakMinimum(jarak, set, n);
        set[m] = true;  // Tandai sebagai sudah dikunjungi

        // 2. Perbarui jarak semua tetangga node m (relaxation)
        for (int j = 0; j < n; j++)
        {
            if (!set[j]              // j belum dikunjungi
                && graf[m][j]        // ada edge m→j
                && jarak[m] != INT_MAX               // m bisa dicapai
                && jarak[m] + graf[m][j] < jarak[j]) // jalur lebih pendek
            {
                jarak[j] = jarak[m] + graf[m][j];  // Perbarui jarak
                parent[j] = m;                      // Catat parent baru
            }
        }
    }

Rekonstruksi Jalur dan Output

C++ 
    // Rekonstruksi jalur dari B (indeks 1) ke belakang menggunakan parent[]
    char namaNode[] = {'A','B','C','D','E','F','G'};
    string jalur = "";
    int curr = 1;  // Mulai dari node tujuan B

    while (curr != -1)
    {
        // Tambahkan nama node di depan string jalur
        jalur = namaNode[curr] + (jalur.empty() ? "" : " -> " + jalur);
        curr = parent[curr];  // Mundur ke node sebelumnya
    }

    cout << "Jarak terdekat A ke B : " << jarak[1] << endl;
    cout << "Jalur                 : " << jalur << endl;
}
Penjelasan Langkah demi Langkah:
  • Inisialisasi: jarak[A]=0, semua lain = INT_MAX, semua set[]=false, semua parent[]=-1
  • Iterasi 1: pilih A (jarak 0) → update tetangga: C=3, F=2
  • Iterasi 2: pilih F (jarak 2) → update: C=min(3,4)=3, B=8, E=5, G=7
  • Iterasi 3: pilih C (jarak 3) → update: E=min(5,4)=4, D=7
  • Iterasi 4: pilih E (jarak 4) → update: B=min(8,6)=6, D tetap 7
  • Iterasi 5: pilih B (jarak 6) → B sudah tujuan, jarak final = 6
  • Rekonstruksi jalur: B→parent=E, E→parent=C, C→parent=A → jalur: A→C→E→B

Contoh Output Langkah per Langkah

Inisialisasi:
  jarak[] = {0, ∞, ∞, ∞, ∞, ∞, ∞}
  set[]   = {F, F, F, F, F, F, F}

  Update C: 0+3=3  < ∞  → jarak[C]=3,  parent[C]=A
  Update F: 0+2=2  < ∞  → jarak[F]=2,  parent[F]=A
  jarak[] = {0, ∞, 3, ∞, ∞, 2, ∞}

Iterasi 2 → pilih F (indeks 5, jarak=2):
  Update B: 2+6=8  < ∞  → jarak[B]=8,  parent[B]=F
  Update C: 2+2=4  > 3  → tidak diperbarui
  Update E: 2+3=5  < ∞  → jarak[E]=5,  parent[E]=F
  Update G: 2+5=7  < ∞  → jarak[G]=7,  parent[G]=F
  jarak[] = {0, 8, 3, ∞, 5, 2, 7}

Iterasi 3 → pilih C (indeks 2, jarak=3):
  Update D: 3+4=7  < ∞  → jarak[D]=7,  parent[D]=C
  Update E: 3+1=4  < 5  → jarak[E]=4,  parent[E]=C
  jarak[] = {0, 8, 3, 7, 4, 2, 7}

Iterasi 4 → pilih E (indeks 4, jarak=4):
  Update B: 4+2=6  < 8  → jarak[B]=6,  parent[B]=E
  jarak[] = {0, 6, 3, 7, 4, 2, 7}

Iterasi 5 → pilih B (indeks 1, jarak=6):
  Jarak final ke B = 6 ✓

Rekonstruksi jalur B:
  B → parent[B]=E → parent[E]=C → parent[C]=A → parent[A]=-1 (stop)
  Jalur: A -> C -> E -> B

5. Kode Lengkap

Berikut adalah kode lengkap implementasi Algoritma Dijkstra dalam C++, mencakup fungsi jarakMinimum(), dijkstra(), dan fungsi main() dengan graf berikut:

C++ 
#include <bits/stdc++.h>
using namespace std;

int jarakMinimum(int jarak[], bool set[], int n) {
    int kecil = INT_MAX;
    int indeks;
    for (int i = 0; i < n; i++) {
        if (set[i] == false && jarak[i] <= kecil) {
            kecil = jarak[i];
            indeks = i;
        }
    }
    return indeks;
}

void dijkstra(int graf[7][7], int awal, int n) {
    int jarak[7];
    bool set[7];
    int parent[7];

    for (int i = 0; i < n; i++) {
        jarak[i] = INT_MAX;
        set[i] = false;
        parent[i] = -1;
    }

    jarak[awal] = 0;

    for (int i = 0; i < n; i++) {
        int m = jarakMinimum(jarak, set, n);
        set[m] = true;

        for (int j = 0; j < n; j++) {
            if (!set[j] && graf[m][j] && jarak[m] != INT_MAX
                && jarak[m] + graf[m][j] < jarak[j]) {
                jarak[j] = jarak[m] + graf[m][j];
                parent[j] = m;
            }
        }
    }

    char namaNode[] = {'A','B','C','D','E','F','G'};
    string jalur = "";
    int curr = 1;
    while (curr != -1) {
        jalur = namaNode[curr] + (jalur.empty() ? "" : " -> " + jalur);
        curr = parent[curr];
    }

    cout << "Jarak terdekat A ke B : " << jarak[1] << endl;
    cout << "Jalur                 : " << jalur << endl;
}

int main() {
    int n = 7;
    int graf[7][7] = {
        {0, 0, 3, 0, 0, 2, 0},
        {0, 0, 0, 1, 2, 6, 2},
        {3, 0, 0, 4, 1, 2, 0},
        {0, 1, 4, 0, 0, 0, 0},
        {0, 2, 1, 0, 0, 3, 0},
        {2, 6, 2, 0, 3, 0, 5},
        {0, 2, 0, 0, 0, 5, 0}
    };
    dijkstra(graf, 0, n);
    return 0;
}

Output Program

Jarak terdekat A ke B : 6
Jalur                 : A -> C -> E -> B
💡 Verifikasi Output:
  • Jalur A → C → E → B memiliki total bobot: 3 + 1 + 2 = 6 ✓
  • Alternatif lain yang lebih panjang: A→F→B = 2+6 = 8 | A→C→D→B = 3+4+1 = 8 | A→F→E→B = 2+3+2 = 7
  • Dijkstra berhasil menemukan jalur optimal dengan bobot minimum = 6

6. Ringkasan Algoritma Dijkstra

Perbandingan Komponen Implementasi:
  • Array jarak[] → menyimpan jarak terpendek saat ini dari sumber ke tiap node. Init: 0 untuk sumber, INT_MAX untuk lain
  • Array set[] → menandai node yang sudah "dikunci" (tidak bisa diperbaiki lagi). Init: semua false
  • Array parent[] → menyimpan node sebelumnya di jalur terpendek untuk rekonstruksi. Init: semua -1
  • jarakMinimum() → memilih node belum dikunjungi dengan jarak terkecil. Kompleksitas: O(n)
  • Loop relaxation → memperbarui jarak tetangga jika ditemukan jalur lebih pendek. Dipanggil n kali
⏱ Kompleksitas Algoritma Dijkstra:
  • Implementasi ini (adjacency matrix + linear search): O(V²) di mana V = jumlah node
  • Implementasi optimal (adjacency list + min-heap): O((V + E) log V)
  • Space complexity: O(V) untuk array jarak, set, dan parent
  • Untuk graf padat (banyak edge), O(V²) bisa lebih baik dari versi heap
⚠️ Batasan Algoritma Dijkstra:
  • Hanya bekerja pada graf dengan bobot non-negatif
  • Untuk graf dengan bobot negatif, gunakan algoritma Bellman-Ford
  • Untuk jalur terpendek antara semua pasangan node, gunakan Floyd-Warshall
  • Implementasi ini hanya mencetak jalur ke node B; bisa dimodifikasi untuk semua node

Kesimpulan

Algoritma Dijkstra adalah salah satu algoritma graf yang paling penting dan banyak digunakan, mulai dari navigasi GPS, routing jaringan komputer, hingga optimasi jalur di game. Kuncinya terletak pada prinsip greedy: selalu pilih node dengan jarak terkecil yang belum dikunjungi, lalu perbarui tetangga-tetangganya (relaxation).

Poin-Poin Penting:
  • Inisialisasi: Jarak sumber = 0, semua lain = ∞, semua belum dikunjungi.
  • Greedy: Setiap iterasi memproses node dengan jarak terkecil — dijamin optimal untuk bobot non-negatif.
  • Relaxation: Inti algoritma — perbarui jarak jika jarak[m] + bobot(m,j) < jarak[j].
  • Parent array: Kunci rekonstruksi jalur — lacak dari tujuan ke sumber secara mundur.
  • Kompleksitas implementasi ini: O(V²). Versi heap lebih cepat: O((V+E) log V).
